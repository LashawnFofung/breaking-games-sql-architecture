# Agent Instructions

Any AI assistant working in this repository, whatever the tool, follows the same rules as the Claude co-pilot.

1. Read [`CLAUDE.md`](CLAUDE.md) first. It holds the data rules and the way we work.
2. Read [`docs/handover.md`](docs/handover.md) next. It says where the work stands.
3. Check [`docs/design-decisions.md`](docs/design-decisions.md) before making any modeling or cleaning choice. If the choice isn't there, propose a new entry rather than deciding silently.
4. Don't build anything listed in [`rejected.md`](rejected.md) without asking.
